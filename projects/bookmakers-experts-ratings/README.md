# Эксперты букмекерской индустрии (bookmakers-experts-ratings)

## Описание

Компактный виджет шириной **660px** со списком экспертов игорного и букмекерского рынка. Без фильтров и заголовков таблицы — только строки с данными. Клик по строке открывает профиль эксперта на [Sports.ru](https://www.sports.ru/?utm_source=special-bookmakers-experts-ratings).

## Возможности

- Три столбца: логотип компании / фото и имя (фамилия жирным) / описание должности и роли.
- Логотипы букмекеров и организаций (ЦУПИС, ЕРАИ, IBA, Первая СРО) по привязке к эксперту.
- Вся строка — ссылка на тег или персону на Sports.ru.
- Адаптивная вёрстка для узких экранов (в т.ч. в iframe на мобильном).
- `resize.js` для автоматической высоты iframe на площадке.

## Данные

- `data/companies.js` — URL логотипов букмекеров и спецорганизаций.
- `data/experts.js` — массив `EXPERTS`: `photoUrl`, `description`, `sportsUrl`, `fullName`, `companyLogo` (35 записей).
