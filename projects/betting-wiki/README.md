# Спортивная вики

## Описание

Энциклопедический раздел о спорте: чемпионы, правила, скандалы, ключевые события, лица и решения. От футбола и баскетбола до зимних видов спорта.

## Возможности

- Главная страница с навигацией по 15 видам спорта
- Табы: Все, Футбол, Баскетбол, Хоккей, Теннис, Автоспорт, Бокс/ММА, Кибер, Фигурка, Лыжи, Плавание + Ещё (Легкая атлетика, Гандбол, Волейбол, Шахматы, Дартс)
- Страницы видов спорта с разделами: Факты, Чемпионы, События
- Оригинальная вёрстка sports.ru
- Клик по статье открывает материал на sports.ru

## Как работают статьи (теги)

Вики **не хранит тексты статей**. Карточки — превью, ссылка ведёт на материал на sports.ru.

### 1. Обновление существующей статьи

Текст, заголовок и картинка живут на sports.ru. Ссылка в карточке не меняется → при открытии пользователь всегда видит актуальную версию. **Пересборка вики не нужна.**

Превью в карточке (заголовок на плитке) обновится:
- **автоматически** — если включена подгрузка по тегам (`articles-loader.js`);
- **вручную** — если карточки зашиты в HTML (текущий режим до настройки тегов).

### 2. Новая статья

Редактор публикует материал на sports.ru и вешает теги, например:

- `Спортивная вики` (корень)
- `Футбол` (вид спорта)
- `Факты` (раздел)

Статья сразу попадает в выдачу GraphQL `byTagIDs`. Если на странице подключён `articles-loader.js` и в `data/tags.js` прописаны ID тегов — **карточка появится без деплоя на dumpster.**

### 3. Иерархия тегов на sports.ru

| Уровень | Тип в API | Пример |
|---------|-----------|--------|
| Корень вики | `MAIN` | Спортивная вики |
| Вид спорта | `CATEGORY` | Футбол, Теннис |
| Раздел | `SUBCATEGORY` | Факты, Чемпионы, События |

Запрос статей (как на оригинальной вики):

```
postQueries.byTagIDs(IDs: [mainId, sportTagId, sectionTagId], ...)
```

### 4. Настройка тегов

1. Создать теги в CMS sports.ru (или переименовать существующие от «Ставочной вики»).
2. Узнать ID: `node scripts/fetch-tag-ids.mjs`
3. Заполнить `data/tags.js` — поля `tagId` у видов спорта и разделов.
4. На блоки статей в HTML добавить атрибуты:
   - главная: `data-wiki-sport="futbol"` на `.categories-block`
   - страница спорта: `data-wiki-sport="futbol" data-wiki-section="fakty"`
5. Подключить в `index.html` и страницах:

```html
<script src="./data/tags.js"></script>
<script src="./articles-loader.js"></script>
```

Пока `tagId: null` — loader не трогает блок, остаётся статический HTML (запасной вариант).

### 5. Деплой на dumpster

- Выкладывается HTML + `patch.js` + `data/tags.js` + `articles-loader.js` (или один standalone-файл).
- При открытии страницы loader запрашивает `https://www.sports.ru/gql/graphql/` — CORS с `dumpster.cdn.sports.ru` разрешён.
- **Новые статьи** появляются после публикации и проставления тегов, без повторной заливки HTML.

## Сборка

```bash
cd projects/betting-wiki
node build.mjs
```

Перед заливкой на dumpster — `node build.mjs`, затем загрузить `index.html` и связанные файлы.

## Локальный просмотр

```bash
npx serve projects/betting-wiki
```
