# Шансы на титул

## Описание

Спецпроект Спортса: таблица всех чемпионов с 2000 года с коэффициентами и вероятностями побед. Интерфейс в стиле списка Forbes — чёрная шапка, фильтры, сортируемая таблица и раскрывающиеся строки с визуалом и описанием.

## Особенности

- Hero-блок с тёмным анимированным фоном **Energy in Motion** (глубокий градиент и световые блики), логотип Спортса, заголовок «Шансы на титул», подзаголовок.
- Блок-продолжение шапки: три карточки с иконками и пояснением, что доступно на странице (коэффициенты, турниры, фильтры).
- Единый тёмный стиль для фильтров, строк таблицы и раскрытых карточек — полупрозрачные панели с обводкой, как в intro-блоке.
- Переключатель **Коэффициент / Вероятность**.
- Сортировка **по дате** и **по кэфу** (повторный клик меняет направление).
- Фильтры **Вид спорта** и **Виды турниров** (названия в кнопках выпадающих списков; мобильная — кнопка «Фильтры»).
- Поиск по имени чемпиона с ассоциативными синонимами (МЮ → Манчестер Юнайтед, ЛА → Лос-Анджелес и т.д.; словарь в `data/search-aliases.js`).
- Липкая панель фильтров: при прокрутке закрепляется сверху (десктоп и мобильная версия).
- Чемпионы The International (Dota 2, 2011–2025) в разделе **Киберспорт**.
- Победители **Tour de France** (2009–2025) в разделе **Велоспорт**.
- Полноширинная вёрстка на десктопе (как в референсе), боковые отступы 48–64px.
- Адаптив: на узком экране — две строки кнопок (**Фильтры / Кэф-%** и **По дате / По кэфу**), внутри «Фильтры»: поиск и выпадающие «Вид спорта» / «Турнир», колонки **Чемпион / Кэф / Турнир** (сезон или год в названии турнира), шапка 500px.
- Шрифты: **TT Bluescreens Trial** (заголовок hero, `fonts/TT_Bluescreens/TT_Bluescreens_Trial_Bold.ttf`), **TT Neoris** (описание, фильтры, значения таблицы; системный fallback + `fonts/TT_Neoris/TT_Neoris_Trial_Variable.ttf`).
- Авто-ресайз iframe (`resize.js`).

## Запуск локально

Откройте `index.source.html` в браузере (нужны `./styles.css`, `./data/*.js`, `./main.js`, `./resize.js`, `./fonts/`).

## Деплой на dumpster

После правок в `index.source.html`, `styles.css`, `main.js`, `data/config.js`, `data/champions.js` или `resize.js`:

```bash
node build-standalone.mjs
```

Скрипт пересоберёт **`index.html`** — один файл со встроенными стилями, шрифтами (base64), данными, логикой и `resize`. Именно **`index.html`** загружайте на [dumpster](https://dumpster.cdn.sports.ru/).

## Данные

- `data/config.js` — виды спорта, турниры, настройки (фильтры «Вид спорта» и «Турниры»).
- `data/champions.js` — массив `allChampionsData` (828 чемпионов с 2000 по 2026 год, включая Tour de France 2009–2025).

### Массовый импорт

1. Положите TSV в `data/champions-import.tsv` (колонки: дата, кэф, вероятность, имя, описание, турнир, вид спорта).
2. `node scripts/import-champions.mjs` — пересоберёт `champions.js`, обновит турниры в `config.js`, сохранит уже заданные `image` по совпадению id/имени.
3. `node build-standalone.mjs` — обновит `index.html` для dumpster.

Ручное добавление: правка `data/champions.js`, затем `node build-standalone.mjs` и загрузка `index.html` на dumpster.
