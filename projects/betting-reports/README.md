# Финансовая отчётность букмекеров

Интерактивная сводка финансовых показателей легальных букмекеров России в стиле Sports: компактная таблица, итоги по рынку и переключение разреза «по букмекерам» / «по годам».

## Описание

Виджет показывает ключевые метрики из открытой отчётности: выручку, прибыль, выигрыши, GGR, целевые отчисления, зарплаты и коммерческие расходы. Вверху — агрегированные суммы по всем букмекерам за выбранный год; ниже — детализация в строках с логотипом и сеткой показателей.

## Возможности

- **Сводка по рынку** — семь карточек с суммой показателей всех БК за год
- **Выбрать «По букмекерам»** — все операторы за выбранный год, сортировка по выручке
- **Выбрать «По годам»** — динамика одного букмекера по годам
- **Динамика год к году** — бейджи изменений у метрик, где есть данные
- **Адаптивная вёрстка** — до 660px, container queries
- **Автоподгонка высоты** — `resize.js` для встраивания в пост

## Запуск локально

Откройте `index.source.html` в браузере (нужны `./styles.css`, `./data/companies.js`, `./main.js`, `./resize.js`).

## Деплой на dumpster

После любых правок в `index.source.html`, `styles.css`, `main.js`, `data/companies.js` или `resize.js`:

```bash
node build-standalone.mjs
```

Скрипт пересоберёт **`index.html`** — один файл со встроенными стилями, данными, логикой и `resize`. Именно **`index.html`** загружайте на CDN (например, [dumpster](https://dumpster.cdn.sports.ru/)).
