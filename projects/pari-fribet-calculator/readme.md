# Калькулятор фрибета

## Описание

Интерактивный виджет-калькулятор, который показывает, сколько фрибета пользователь получит при первом депозите в рамках бонуса БК Пари (100% на первый депозит). Пользователь вводит сумму депозита или двигает ползунок — три карточки мгновенно пересчитывают депозит, размер бонуса и необходимый оборот для вывода.

## Возможности

- Поле ввода и ползунок внутри первой карточки
- Три карточки: ввод депозита → доступный фрибет → сумма ставок для вывода
- Расчёт бонуса: 100% от депозита (мин. 100 ₽, макс. 20 000 ₽)
- Расчёт оборота: бонус × 15
- Предупреждения при депозите ниже минимума и при достижении лимита бонуса
- Адаптивная вёрстка: горизонтальные карточки на десктопе, вертикальный поток со стрелками на мобилке
