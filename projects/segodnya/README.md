# Сегодня - Календарь спортивных событий

## Описание

Интерактивный календарь исторических спортивных событий. Каждый день года содержит подборку самых интересных и ярких моментов из истории спорта: рождения легенд, знаковые матчи, трансферы, мировые рекорды, награды и скандалы.

## Возможности

- **Навигация по датам** - просмотр событий для любого дня года с помощью календаря или стрелок навигации
- **Фильтрация по видам спорта** - выбор одной или нескольких категорий: футбол, баскетбол, хоккей, теннис, автоспорт, бокс и ММА, фигурное катание, лыжи и биатлон, волейбол, гандбол и другие виды спорта
- **Детальная информация** - полное описание каждого события с годом, категорией и тегами
- **Система рекомендаций** - связанные события для более глубокого погружения в историю
- **Адаптивный дизайн** - удобный просмотр на любых устройствах
- **Стиль Sports.ru** - фирменный дизайн в стиле Sports.ru с использованием брендированных шрифтов и цветов

## Типы событий
