# Виджет отзыва эксперта

## Описание
Адаптивный виджет для отображения отзывов экспертов Sports.ru внутри постов. Виджет включает фотографию эксперта, имя, должность, текст отзыва и декоративные кавычки.

## Особенности
- Адаптивный дизайн для десктопа и мобильных устройств
- Ширина на десктопе: 770px, минимальная высота: 120px
- Круглая фотография эксперта
- Фирменные шрифты и цвета Sports.ru
- Декоративные кавычки в стиле бренда
- Белый полупрозрачный фон для естественной интеграции
- Автоматическое изменение размера iframe для интеграции в посты
- Закругленные углы и современный дизайн
