# Монополия — Armenia Edition

## Описание

Локальная десктопная версия классической «Монополии» с армянским колоритом. Все суммы в драмах (AMD) по курсу 1$ ≈ 1 000 ֏. Игроки ходят по очереди, бросают кубики, покупают участки, платят аренду, тянут карточки «Казна» и «Шанс», строят дома и закладывают имущество.

## Возможности

- 2–6 игроков за одним компьютером (hot-seat)
- Стартовый капитал: 1 500 000 ֏
- Полное игровое поле из 40 клеток с армянскими названиями
- Бросок кубиков и пошаговое движение по правилам
- +200 000 ֏ за каждый проход через Старт
- Покупка участков, аренда, монополии, дома и отели
- Коммунальные предприятия (Գազ, Լույս) и спецобъекты (4 «вокзала»)
- Карточки Казны и Шанса на армянском языке
- Тюрьма, штраф 50 000 ֏, карты выхода
- Залог участков (50% стоимости)
- Определение победителя при банкротстве соперников
- Автономная версия `index.standalone.html` для деплоя на CDN (все стили и скрипты внутри одного файла)
