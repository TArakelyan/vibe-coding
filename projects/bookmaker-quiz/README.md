# 🎯 Опросник для подбора букмекера

Интерактивный мини-опросник для подбора наиболее подходящего букмекера на основе предпочтений пользователя.

## 📋 Описание

Приложение задает пользователю 7 ключевых вопросов о его предпочтениях:

1. **Популярность** - Важна ли популярность БК?
2. **Надежность vs Коэффициенты** - Что важнее?
3. **Скорость вывода vs Удобство приложения** - Что в приоритете?
4. **Размер бонуса** - Насколько важны стартовые бонусы?
5. **Долгосрочные ставки** - Интересуют ли долгосроки?
6. **Экспрессы** - Планируете ли делать экспресс-ставки?
7. **Источник оценки** - Что важнее: оценка редакции или мнение пользователей?

На основе ответов приложение рассчитывает наиболее подходящего букмекера из базы данных.

## 🚀 Запуск

Просто откройте файл `index.html` в браузере. Никаких дополнительных зависимостей не требуется.

## 💡 Принцип работы

1. **Сбор ответов**: Каждый ответ имеет вес от 0 до 10 для соответствующего критерия
2. **Расчет баллов**: Для каждого букмекера рассчитывается итоговый балл по формуле:
   ```
   Итоговый балл = Σ (Вес ответа × Оценка БК по критерию)
   ```
3. **Ранжирование**: Букмекеры сортируются по убыванию итогового балла
4. **Результат**: Показывается топ-1 букмекер и еще 3 альтернативных варианта

## 📊 Критерии оценки

Каждый букмекер оценивается по 10 критериям (шкала 1-10):
- Популярность
- Надежность
- Коэффициенты
- Скорость вывода
- Удобство приложения
- Размер бонуса
- Долгосрочные ставки
- Экспресс-ставки
- Оценка редакции
- Рейтинг пользователей

## 📝 Добавление новых букмекеров

Чтобы добавить нового букмекера, добавьте его в файл `bookmakers-data.js`:

```javascript
'новый-букмекер': {
  name: 'Название',
  logo: 'URL логотипа',
  scores: {
    popularity: 8,
    reliability: 9,
    coefficients: 7,
    withdrawSpeed: 8,
    appConvenience: 9,
    bonusSize: 8,
    longTermBets: 7,
    expressBets: 8,
    editorialRating: 8,
    userRating: 8
  },
  description: 'Описание букмекера'
}
```
