# 🎯 Опросник для подбора букмекера

Интерактивный мини-опросник для подбора наиболее подходящего букмекера на основе предпочтений пользователя.

## 📋 Описание

Приложение задает пользователю 7 ключевых вопросов о его предпочтениях:

1. **Популярность** - Важна ли вам популярность букмекерской компании? (Да/Нет)
2. **Надежность vs Коэффициенты** - Что для вас важнее: надежность БК или высокие коэффициенты?
3. **Удобство приложения vs Скорость вывода** - Что для вас важнее: удобство приложения или скорость вывода средств?
4. **Размер бонуса** - Чем больше сумма стартового бонуса, тем лучше? (Да/Не всегда/Нет)
5. **Долгосрочные ставки** - Интересны ли вам ставки на долгосрочные события? (Да/Нет)
6. **Экспрессы** - Планируете собирать экспрессы? (Да/Иногда/Нет)
7. **Источник оценки** - Что для вас важнее: оценка редакции "Спортса" или мнение других пользователей?

На основе ответов приложение рассчитывает и показывает наиболее подходящего букмекера.

## 💡 Принцип работы

1. **Сбор ответов**: Каждый ответ имеет вес от 0 до 10 для соответствующего критерия
2. **Расчет баллов**: Для каждого букмекера рассчитывается итоговый балл по формуле:
   ```
   Итоговый балл = Σ (Вес ответа × Оценка БК по критерию)
   ```
3. **Ранжирование**: Букмекеры сортируются по убыванию итогового балла
4. **Результат**: Показывается наиболее подходящий букмекер с его логотипом

## 📊 Критерии оценки

Каждый букмекер оценивается по 10 критериям (шкала 1-10):
- Популярность
- Надежность
- Коэффициенты
- Скорость вывода
- Удобство приложения
- Размер бонуса
- Долгосрочные ставки
- Экспресс-ставки
- Оценка редакции
- Рейтинг пользователей
